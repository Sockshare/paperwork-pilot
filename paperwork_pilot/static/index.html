        ❔ How to use Paperwork Pilot
        
  
        
    
          
      
        1. Add a document. Drag a file in, click to choose one, or paste the text. Photos of paper work too (needs a clear photo).
          2. 
      
        2. Wait a moment. The app reads it and explains it in plain words.
          3. 
      
        3. Read the cards. Start with Watch out for, then Dates and Money.
          4. 
      
        4. Take action. Click Write a reply to get a ready-to-send letter, or Ask a question.
          5. 
    
        
    
        Is it private?
        
    
        Yes, when the AI runs "On my computer" or in "No AI" mode, nothing is sent anywhere. If you choose a cloud key, your document text is sent to that AI company.
        
    
        Something not working?
        
    
        In a terminal, run python scripts/selfcheck.py — it checks your setup and tells you what to fix. The file docs/TROUBLESHOOTING.md in the app folder lists every error message with its fix.
